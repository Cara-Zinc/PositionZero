# 红王与黑后：六视角建模设计图

使用内置 ImageGen，依据已确认的单枚瓷器棋子图生成。供 Position Zero 3D 棋子建模参考；不修改应用代码或现有二维棋子。

- 每张图 3 列 × 2 行：第一行正面、背面、左侧；第二行右侧、顶部、底部。
- 红王基准：`../porcelain-imagegen-v1/originals/white-king.png`（文件名 white 对应棋规白方，视觉为红方）。
- 黑后基准：`../porcelain-imagegen-v1/originals/black-queen.png`，沿用黑金服饰向上延伸的最小遮挡版本，不采用高领长袖版本。
- 同一棋子的姿态、饰物和色彩应锁定；背面装饰、围裙系带、后发和底座 underside 等缺少参考的部分是本次建模补全，不是原艺术品的实测复刻。
- 白色背景和视角标签用于图纸辨识；与前一批透明单枚 PNG 用途不同。

这些是生成式建模参考，不是由已完成的同一 3D 网格渲染而来的尺寸精确工程图。各视角可能仍有局部投影或纹样误差；建模时应以已确认的单枚图锁定造型，统一背面/侧面纹样及部件坐标。

初稿存放在 `drafts/`；初始提示词见 `prompts.json`，投影修订提示词见 `projection-correction-prompt.txt`。本轮仅涉及两个棋子。
