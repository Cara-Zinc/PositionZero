# 红黑瓷塑 ImageGen 棋子

来源：`../red-black-porcelain-v3.png`，制作日期：2026-10-02。

十二枚棋子分别通过内置 ImageGen 生成，保留概念稿的釉面、手绘装饰、衣褶与雕塑体积。明确要求真正透明背景，不绘制棋盘、文字、外部底座或地面投影。

## 文件组织

- `originals/`：十二张原始生成 PNG，保持生成像素与 alpha。
- `pieces/`：十二张 512 × 512 PNG，用于后续棋盘接入。
- `preview.png`：十二枚总览，以及 48、64、96 px 棋格尺寸检查。
- `board-preview.png`：完整初始局面与西班牙开局 7…d6 后局面。
- `prompts.json`：每枚棋子的完整提示词。
- `manifest.json`：角色、阵营、文件名与画布尺寸。

文件名 `white-*` 对应红方视觉与棋局 `w`；`black-*` 对应黑方与 `b`。不同阵营的造型以参考图为准，不用同一棋子直接换色。

## 正方形格子适配

生成阶段要求适度缩短躯干、裙摆与裤腿，减薄自身底座，同时保留自然的头脸和手部比例。ImageGen 对比例的执行并非精确几何变换，仍需按预览逐枚审阅。

整理阶段裁掉完全透明的外部留白，保持宽高比缩放到 512 px 正方形画布，统一落脚基线 y=470。王、后、象、马、车、兵使用不同的可见高度，避免每枚都等高。没有对棋子做全局横向拉伸，也没有重新分色描摹。

单枚 PNG 可以直接用于 `<img>`，不需要套进 SVG。像素资源预先生成并保存到本地，应用运行时无需请求 ImageGen。

## 重建整理输出

```sh
node scripts/prepare-porcelain-sprites.mjs /absolute/path/to/sharp/package.json
```

此脚本只负责 alpha 留白裁切、等比缩放、画布对齐与预览排布。发现无 alpha 或不透明背景时会报错，不会猜测颜色并抠图。

目前为设计资产交付，尚未替换 Position Zero 中已有的棋子或皮肤。正式接入前应继续检查深浅格、选中态、夜间模式及小尺寸辨识。
# 黑后造型调整（v2）

黑后已按原艺术品与获认可的概念图重制：恢复象牙白肩颈及手臂、原有斜垂手势、贴身黑裙、黑金纹样、腿侧丰饶角及金币。仅将原黑金服饰向上延伸为不透明的胸部遮挡，不再采用高领长袖上衣。当前 `originals/black-queen.png`、`pieces/black-queen.png` 和预览均使用 v2。被否决的 v1 留存在 `revisions/`；本次内置 ImageGen 提示词见 `black-queen-v2-prompt.txt`，优先于批次 `prompts.json` 中的旧黑后提示词。
