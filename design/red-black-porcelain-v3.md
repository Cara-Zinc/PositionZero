# 红与黑瓷塑方案 v3

日期：2026-10-02。用途：以实物外形为约束的视觉设计提案，尚未接入应用。

## 参考与阵营映射

- `Red and White chess set - Open Chess Museum_files/red-and-white-chess-set_1.jpg`：原白方实物，映射为新版黑方。
- `red-and-white-chess-set_files/red-and-white-chess-set_2.jpg`：原红方实物，继续作为新版红方。

本版以这两张照片为直接造型依据，优先保持姿态、服装、持物、轮廓与比例，仅重新组织釉色并减少细碎装饰。原白方的裸露瓷质肤色保留象牙色，不为了黑方面积而把皮肤全部涂黑。

## 与 v2 的关键差异

| 棋子 | v2 的偏差 | v3 造型约束 |
| --- | --- | --- |
| 红方象 | 高尖帽长袍人物 | 布琼尼帽、三道横向衣扣、黑腰带、双手在腰带两侧、裤腿和高靴分开可见的军人 |
| 黑方象 | 高尖帽与竖直持物 | 偏斜的金色军帽、胸甲、腰前弯曲的手臂、一手扶腰、侧挂刀鞘与高靴 |
| 黑方后 | 宽裙、胸前丰饶束 | 瘦长姿态、裸肩和双臂、双手斜向下、贴身黑裙、腿旁倾倒金币的丰饶角 |
| 红方车 | 阶梯船体和旗杆 | 卷曲船首与低船体，上部为侧转人物与宽阔非对称披衣／帆形，不加旗杆 |
| 黑方车 | 阶梯船体和旗杆 | 波浪纹船体，上部为金色头盔人物与向侧面扫开的盾／帆形披衣，不加旗杆 |

其他棋子也重新按实物约束：红王恢复工作帽、敞领上衣和长围裙；红后恢复圆弧头饰、仰头姿态及侧面的花饰束；黑王恢复铠甲和腿部结构；红兵恢复胸前麦穗与镰刀；黑兵恢复偏头姿态及三道横向锁链。

“披衣／帆形”等描述是对照片可见轮廓的造型描述，不作为艺术品图像学身份的定论。单张照片看不到的背部结构不补造为历史事实。

## 配色

- 朱红釉：`#B52A35`
- 浅红釉：`#D58B8F`，保留原红方粉红与深红的服装层次
- 黑釉：`#25272C`，用于原白方服装和局部船体
- 象牙瓷：`#EFEAE2`，用于裸露皮肤与陶瓷留白
- 旧金：`#B99A60`，用于实物已有的饰边、军帽、胸甲与器物

本版不强制黑色衣饰达到某个面积比例；先尊重裸体／服装分区，再通过底座、服装和轮廓配色建立阵营区分。

## 视觉复核

已对照两张照片检查十二枚棋子：重点五枚均恢复相应的大轮廓、服装和持物关系；双方车取消阶梯塔与旗杆，黑后恢复腿侧金币和斜向下的手臂。其余棋子也恢复工作围裙、圆弧头饰、紧凑马颈与偏头锁链兵。

生成稿仍有局部装饰与比例解释，不是实物的测绘复刻。黑车、黑马与黑王底座保留较多象牙瓷留白，阵营辨识必须在后续实际棋盘上复核。输出由内置 ImageGen 生成，尺寸为 1536 × 1024；应用代码与旧稿未覆盖。
