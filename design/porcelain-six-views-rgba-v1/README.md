# 独立透明六视角参考图

红王与黑后各六张独立 PNG，以 `../porcelain-six-views-v1/` 的 v2 六视图对应格子为参考，使用内置 ImageGen 逐视角提取，移除白底、文字与分隔线。保留象牙白瓷器本身，不按白色阈值抠图。

目录：`red-king/`、`black-queen/`。

| 文件 | 视角 | 原图对应格 |
| --- | --- | --- |
| front.png | 正面 | 上排左 |
| back.png | 背面 | 上排中 |
| left.png | 左侧 | 上排右 |
| right.png | 右侧 | 下排左 |
| top.png | 顶部 | 下排中 |
| bottom.png | 底部 | 下排右 |

左右命名沿用六视图标签。顶部是俯视投影，底部仅为象牙白底座 underside。所有图采用真实 RGBA 透明背景，不含棋盘格背景或文字。

注意：ImageGen 提取可能带来局部纹样、轮廓与材质细节的变化，并非原图的逐像素裁切；也不是由同一已完成 3D 网格渲染的几何精确投影。不同视角独立居中，不能直接用像素尺寸比较真实物理尺寸。建模时应统一部件坐标、纹样和底座形状，以先前获认可的单枚图锁定造型。

本次不修改应用代码。提示词保存在 `prompts.json`；透明通道与尺寸信息见 `manifest.json`。
