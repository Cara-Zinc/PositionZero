# 红与黑 · 抽象化概念稿 v1

在获认可的 ImageGen 瓷器棋子版本上追加设计探索，不替换原版，不改应用中的棋子。

## 视觉方向

- 从写实瓷器转向平面珐琅／套色版画式插画：保留有机曲线，减少高光、渐变和体积塑造。
- 主色保持朱红、深红、炭黑、象牙白、古金；以大色块和少量阴影面组织层次。
- 通过缩短腿部与裙身、展开围裙和披风来增加轮廓宽度，不整体拉伸图片。近方形是设计目标，不要求所有角色统一轮廓。
- 面部、麦穗、金叶纹、盔甲与鬃毛简化为少量可辨识的笔画，优先检查小尺寸识别。

## 不应丢失的符号

| 棋子 | 红方 | 黑方 |
| --- | --- | --- |
| King | 工人帽、围裙、铁锤 | 金冠、骷髅面、黑兜帽长袍、双手扶中央竖剑；不再使用甲胄与短棒 |
| Queen | 圆形头饰、仰首、花纹披布 | 斜垂手臂、贴身黑裙、丰饶角、金币；仅胸部做黑金遮挡 |
| Bishop | 星徽尖军帽、三道衣襟扣、腰带 | 斜军帽、胸甲、黑披风 |
| Knight | 粉红马头、金鬃、红色折叠披布 | 象牙白马头、黑色缰具、金色颈饰 |
| Rook | 红舟、金卷浪、披风帆形 | 白舟、黑金盾徽、金色双层浪纹 |
| Pawn | 麦穗、镰刀 | 倾斜头部、三排锁链 |

## 文件与边界

- `concept.png`：内置 ImageGen 生成的透明背景概念总览。
- `black-king-death-original.png` / `black-king-death-512.png`：按用户提供的早期持剑死神方案重制的黑王，后者为方格使用的透明 512×512 画布。此方案优先于总览中的甲胄黑王；总览尚未重新生成。
- `black-king-death-prompt.txt`：持剑死神黑王的内置 ImageGen 提示词。
- `prompt-initial.txt` / `prompt-refinement.txt`：初次生成与进一步抽象化的提示词。
- 这是位图设计稿，不是真正的 SVG，也未拆分为 12 个可直接用于棋盘的资源。
- 后续 SVG 应手工构建少量平滑路径并检查 48 / 64 / 96 px 效果，不把位图嵌入 SVG，也不自动描摹全部细节。

当前写实版本继续保留在 `../porcelain-imagegen-v1/`。
