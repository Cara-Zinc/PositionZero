# 红与黑 · 统一风格概念稿 v2

以新版持剑死神黑王为风格基准，重新统一全套 12 枚棋子的轮廓、色块、衣褶与金色边饰。内置 ImageGen 制作，不覆盖写实版或抽象化 v1，不改应用代码。

## 本次调整

- 黑王采用金冠、骷髅面、黑兜帽长袍和双手扶中央竖剑，不再使用甲胄与短棒。
- 全套采用清晰外轮廓、少量大块明暗面与流动曲线，减少写实瓷器反光与细碎装饰。
- 保留红王工人帽与铁锤、红后圆头饰、双方 bishop 军装、舟形 rook、麦穗兵与三排锁链兵等符号。
- 黑后保留斜垂手势、贴身黑裙、胸部黑金遮挡、丰饶角及金币。
- 底座与金色边饰更统一；比例仍为艺术概念，不承诺全部轮廓已接近正方形。

## 文件

- `concept.png`：透明背景的 12 枚棋子概念总览。
- `preview.png`：将透明稿铺在浅色底上的查看用预览；不改变透明原稿。
- `in-app-auction.jpg`：接入后在本地应用预览中的验证截图。
- `in-app-auction-large.jpg`：棋盘中红黑棋子放大 1.3 倍后的验证截图；仅调整显示尺寸，原 PNG 不变。向上微移以保持底座和最高棋子完整位于方格内，其他主题与换装小预览尺寸不变。
- `prompt.txt`：统一风格的生成提示词。
- `prompt-alpha.txt`：仅移除生成背景、保留棋子的编辑提示词。

已拆分为 12 枚透明 512×512 PNG，保存在 `pieces/`，运行副本位于 `public/pieces/red-black/`；接入 `Auction oxblood`（猩红）主题。其他主题继续使用原标准棋子。它们是位图资源，不是真正 SVG。当前写实素材、抽象 v1 和独立持剑黑王均完整保留。

使用 `scripts/prepare-abstract-pieces.mjs` 从透明稿提取独立连通轮廓，保留原比例和抗锯齿边缘，统一底座基线；传入已安装的 sharp package.json 路径。日常 `npm run sync:assets` 会同步已生成的 PNG，无需重新生成图片。
